Platzhalter in den Texten
Du kannst Variablen verwenden, die beim Vormerken einer Nachricht automatisch ersetzt werden.
Platzhalter	Bedeutung
{buchung_id}	Anmeldungsnummer
{status}	Aktueller Buchungsstatus
{flasche}	Flaschenbezeichnung
{termin}	TÜV-Termin
Beispielsweise könnte eine Abholbenachrichtigung so aussehen:
BETREFF
Ihre TÜV-Flasche kann abgeholt werden – Anmeldung #

NACHRICHT
Guten Tag,
Ihre Flasche  zur TÜV-Anmeldung # kann abgeholt werden.
Mit freundlichen Grüßen
Ihr Verein
